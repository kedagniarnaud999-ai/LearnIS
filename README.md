# LearnIS — AI-Powered Cognitive Tutor

> **Guiding learners through questions, not answers.**

LearnIS (Learning Intelligence System) is an AI-powered tutoring system designed to use generative AI as a learning partner rather than an answer machine. It guides learners through structured Socratic dialogue, cognitive scaffolding and progressive questioning to strengthen reasoning, autonomy and creativity.

## Problem

Generative AI can make learning easier but can also encourage learners to copy answers without understanding the underlying reasoning. This can weaken analytical skills and create dependency on AI.

## Solution

LearnIS makes the learner's reasoning process the center of the interaction. Instead of immediately giving an answer, the system probes prior knowledge, asks progressive questions, provides conceptual guidance, proposes exercises and assesses mastery.

## Pedagogical protocol

1. **Exploration** — identify prior knowledge
2. **Guided questioning** — lead the learner toward insight
3. **Orientation** — provide analogies, examples and useful sources
4. **Consolidation** — test understanding and expose misconceptions
5. **Assessment** — measure mastery and adapt scaffolding

## Key features

- Socratic Dialogue Engine
- AI Dependency Indicator (ADI)
- Competency Mastery Score
- Adaptive scaffolding
- Structured learning metrics
- Offline-first direction for low-connectivity environments

## Project status

🟢 **Functional prototype / hackathon project**

LearnIS was developed for the Gemma 4 Good Hackathon organized by Kaggle and Google DeepMind in 2026. The current repository documents the core concept, pedagogical protocol and prototype architecture. The next stage is to validate the learning methodology with real learners and strengthen evaluation of cognitive autonomy and mastery.

## Target users

- Secondary and university students
- Self-directed learners
- Vocational and digital-skills learners
- Learners in contexts with limited access to qualified tutoring

## Vision

LearnIS is designed around a simple principle: **AI should help people learn how to think, not think instead of them.**
